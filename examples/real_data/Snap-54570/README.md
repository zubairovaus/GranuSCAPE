# GranuSCAPE: Real-Image Demonstration

This directory contains a real fluorescence microscopy image of a mouse olfactory bulb tissue section and the corresponding results generated using GranuSCAPE.

The example is provided to support reproducibility, facilitate inspection of segmentation quality, and demonstrate the data structures produced by the pipeline.

## 1. Input Image

**File:** `input/Snap-54570.czi`

The image was acquired using a Zeiss Axio Imager.M2 widefield fluorescence microscope equipped with an Axiocam 506 mono camera and an EC Plan-Neofluar 40×/0.75 objective.

- Image dimensions: 2752 × 2208 pixels
- Pixel size: approximately 0.1802 µm/pixel
- Fluorescence channels: DAPI, AF488, G3BP1/2, and eIF3η

The original Zeiss CZI format is preserved to retain image data and acquisition metadata.

## 2. Analysis Results

**File:** `results/Snap-54570.h5`

The HDF5 file contains the stored processing results generated by GranuSCAPE. It can be used to inspect existing analysis outputs and, where supported by the installed software version, rerun spatial analysis without repeating the initial segmentation.

**Directory:** `results/qc/`

This directory contains quality-control outputs generated during image processing. These files can be used for visual inspection of segmentation and cellular assignments.

## 3. Analysis Workflow

GranuSCAPE supports the following analysis stages:

1. Segmentation of cellular and nuclear structures.
2. Identification of the mitral cell layer and selection of candidate mitral-cell profiles.
3. Conservative refinement of somatic boundaries.
4. Soma-guided assignment of a primary nucleus to each cell.
5. Identification of G3BP- and eIF3η-positive puncta.
6. Nucleus-centered spatial profiling and optional geometry-constrained Monte Carlo analysis.

The HDF5 file provides an example of the pipeline's stored output. The availability of individual result groups depends on the processing stages executed.

## 4. Reusing the Example

The original CZI file can serve as input for a new GranuSCAPE analysis.

The accompanying HDF5 file can serve as input for postprocessing and spatial reanalysis, subject to the configuration and dependencies of the installed GranuSCAPE version.

Example configuration templates are available in the parent `examples/` directory. Local paths and software backend settings may need to be adjusted.

The bundled results are provided for demonstration and inspection; exact reproduction requires the processing configuration and software versions used to generate them.
